# Node-RED Labs

Questa cartella raccoglie tracce e flow dei laboratori di **Node-RED**:
- [`lab1/`](./lab1/) — Esercizi del Lab 1 (OpenWeatherMap, File/Context Sharing, MQTT, HTTP REST)
- [`lab2/`](./lab2/) — Esercizi del Lab 2 (Telegram Chatbot con `node-red-contrib-chatbot`)
- `lab-userdir/` — `userDir` isolata usata da `Node-RED Lab 1` e `Node-RED Lab 2`, così da non mescolare `context/` o file `.sqlite` con [`../nodered-exam/`](../nodered-exam/) né con [`../nodered-practice/`](../nodered-practice/).

Per iniziare subito con i template pronti delle lezioni, consulta [`../nodered-lab-template/README.md`](../nodered-lab-template/README.md).
